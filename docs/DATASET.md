# Dataset Guide

LogInsight is an in-memory analyzer: at most **one dataset** is loaded at a time, and every product
number (dashboard, analytics, patterns, incidents, benchmarks) is computed live from it. When
nothing is loaded the product endpoints answer 404 and the UI shows first-run states.

## Sources

1. **Demo Dataset** (recommended) — `POST /api/datasets/demo` (or `POST /api/ingestion/demo`).
   Generated by `DemoDatasetGenerator`:
   - deterministic corpus anchored at seed `2026-09-13`, re-anchored to the **current hour** so
     ranges like `1h` look alive;
   - **14,000 events**, 8 services (`api-gateway, auth-service, user-service, payment-service,
     order-service, notification-service, database, cache`);
   - correlated **error bursts** (times of day flagged in the generator) so the incident detector,
     top patterns and timeline have real structure to surface;
   - realistic fields: hosts, IPs, request/user ids, HTTP method/endpoint/status, response time,
     trace/span ids, source, raw line, extra attributes.
   - `generate()` is cached per instance; `build(int, Instant)` is deterministic for fresh instances.
2. **Bundled samples** — `GET /api/datasets` lists files in `sample-data/`; `POST /api/datasets/{name}`
   loads one with the bare file name as the dataset name (used by the tests).
3. **File upload** — `POST /api/datasets` (multipart `file`, optional `name`). The parser
   auto-detects **JSONL** (`JsonLogParser`) or **canonical text** (`TextLogParser`).

## Parse honesty

- Every parsed line becomes a `LogEvent`; unparseable lines are counted in `failedLines`, **never
  silently dropped**.
- The summary reports the real result: `size` (events), `totalLines`, `failedLines`, `loadedAt`.
- `rawMessage` preserves the original line; `message` is the cleaned/normalised text used for
  display and search.

## Status endpoints

- `GET /api/ingestion/status` → `{ dataset, parser, streaming, availableSamples, sampleCount }`.
- `GET /api/datasets/current` → the active dataset summary or a 404 body `{ loaded: false }`.
- `DELETE /api/datasets` → clears the dataset (all screens return to first-run state).

## Demo vs. "real traffic"

The **live stream** replays the loaded dataset oldest-first at a bounded pace. It always reports
`source: "demo-replay"` and the label *"Demo replay stream — not real-time"*. The UI keeps that
label visible. Demo-generated events carry the same labels — nothing is presented as a production
feed.

## Life-cycle

```
start (no dataset) → load demo / sample / upload → analyse → clear → first-run again
```

Analytics re-derive per request (cached only by dataset instance), so a new dataset immediately
reflects everywhere.
